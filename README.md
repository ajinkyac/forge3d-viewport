# @forge3d/viewport

A React Three Fiber viewport library for 3D applications.

## Installation

```bash
# npm
npm install @forge3d/viewport three @react-three/fiber @react-three/drei

# pnpm
pnpm add @forge3d/viewport three @react-three/fiber @react-three/drei

# yarn
yarn add @forge3d/viewport three @react-three/fiber @react-three/drei
```

### Peer Dependencies

The following packages must be installed in your project:

| Package              | Version    |
| -------------------- | ---------- |
| `react`              | `^18.0.0`  |
| `react-dom`          | `^18.0.0`  |
| `three`              | `^0.160.0` |
| `@react-three/fiber` | `^8.0.0`   |
| `@react-three/drei`  | `^9.0.0`   |
| `three-stdlib`       | `^2.0.0`   |
